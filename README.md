## Jak uruchomić projekt?

### 1. Pobierz repozytorium

Sklonuj repozytorium:

``` bash
git clone https://github.com/Karolinka4/EmotiScape-projekt_magisterski.git
```

Możesz również pobrać projekt jako ZIP:

`Code → Download ZIP`

Następnie rozpakuj pobrane archiwum.

### 2. Otwórz projekt w Unity

1.  Uruchom Unity Hub.
2.  Wybierz `Add → Add project from disk`.
3.  Wskaż folder z projektem EmotiScape.
4.  Otwórz projekt.
5.  Poczekaj, aż Unity zaimportuje wszystkie wymagane pliki i pakiety.

### 3. Uruchom projekt

Podłącz kompatybilny zestaw VR, otwórz główną scenę projektu, a
następnie naciśnij przycisk `Play`.

## Rozwój projektu

Po pobraniu repozytorium wystarczy dodać projekt do Unity Hub i go
otworzyć.

Unity automatycznie zaimportuje zasoby oraz przywróci pakiety wymagane
przez projekt.

W repozytorium zalecane jest korzystanie z pliku `.gitignore`
przeznaczonego dla projektów Unity.
